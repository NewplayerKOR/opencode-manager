# DESIGNS.md — 어떻게 생겨야/동작해야 하는가

> 최종수정일: 2026-09-26 / 상태: v2 개정 / 전제: Python + Tkinter/PySide, Windows 우선, 읽기전용

## 1. GUI 구조 (2영역 + 진단 축소)
- 메인: 좌측 `프로젝트(활성/비활성 두 그룹)` + 우측 `세션명 목록 + 상세` 2영역 분할. 프로젝트 선택 시 해당 세션 목록 갱신.
- 보조: `대시보드` 요약 바(상단 한 줄: 용량/건수), `진단`은 별도 탭이 아닌 상세 패널 내 배지/문구로 축소. 설정 화면 없음(1단계).
- 레이아웃: 좌측 트리/테이블(프로젝트) + 우측 테이블(세션) + 최우측 또는 하단 상세 패널. 하단 상태바에 `읽기전용` 표시 + 마지막 새로고침 시각.

## 2. 시각 규칙
- 색상: 1단계는 파랑/회색 중심. 빨강(위험)은 V2 삭제 기능 예약이므로 진단에서도 "주의(주황)"까지만 사용. 확정적 위험 표현 금지, "의심" 표현 사용.
- 용량은 `MB` 소수 1자리 + 원본 bytes를 툴팁/상세에 병기. 건수는 천 단위 구분.
- 빈 상태: "세션 없음"이 아니라 "이 프로젝트의 조회 결과 0건 (DB 잠금 여부 확인)"처럼 원인 힌트 포함.
- 세션명 표시: DB title 우선, 없으면 `id 앞 8자 + 날짜` 대체 표기. 대체 표기에는 "(자동 표기)" 꼬리표 병기.

## 3. 경로 표기 규칙 (Windows 핵심)
- 화면에는 **원본 경로 그대로** 표시 (`C:\Dev\...`, `\` 유지, 대소문자 유지).
- 비교/매칭용 정규화값은 별도 컬럼/상세 필드로 병기. 정규화 규칙(초안, T06에서 확정):
  1. `/` → `\` 통일, 중복 구분자 제거, 끝 구분자 제거
  2. 대소문자 무시 비교 (Windows이므로, 표시 원본은 보존)
  3. UNC/`\\wsl$` 경로는 별도 배지 표시, 동일 취급하지 않음
- symlink/reparse point(OneDrive 등) 의심 시 "정규화 불일치 의심" 배지만 표시, 자동 판단 금지.

## 4. 안전 UX 규칙 (위반 금지)
- 쓰기/삭제 버튼을 만들지 말 것. 진단 문구는 안내형: 예) "Desktop을 종료한 뒤 수동 백업을 권장합니다. 경로는 F05 백업 가이드 참조."
- DB 잠금/파싱 실패 시 크래시 금지. 상태바 + 해당 패널에 안내 문구 표시하고 나머지 탭은 정상 동작.
- `새로고침`은 수동 버튼만. 자동 폴링 금지 (DB/WAL 부하 방지).
- 프로젝트/세션 행의 체크박스는 판단 보조용(메모/내보내기 대상 표시)으로만 사용. 삭제 실행과 연결 금지(1단계).
- 경로/ID는 `복사` 버튼 제공. 사용자가 수동 조치할 수 있게 돕는 범위까지만.

## 5. 코드 규칙 (향후 구현 세션용, PM이 검수 시 사용)
- 경로: `pathlib` + 환경변수(`%USERPROFILE%`, `%APPDATA%`) 경유. 하드코딩된 `C:\Users\...` 금지.
- SQLite: `sqlite3.connect(f"file:{p}?mode=ro", uri=True)` 강제. `timeout=5` 내외, 실패 시 안내 예외로 변환.
- `.dat` 파싱: T03 결론 전까지 바이너리 직접 해석 시도 금지. 크기/존재/목록 수준까지만.
- OS 분기: 경로 상수를 `paths_win.py` 등에 분리. macOS/Linux 상수는 주석/미사용으로만.
- 로깅: 조회 실패(잠금, 파싱 실패)는 로그 + 화면 안내. 스택트레이스 직접 노출 금지.
- 주석·docstring은 한글 또는 영어만 사용. `AGENTS.md` §4-3 문체 점검 대상.
- 테스트: 실데이터 직접 검증 금지. fixture/복사본 DB로만. 실측이 필요하면 읽기전용 조회 결과(수치)만 `TASKS.md`에 기록.

## 6. 용어 통일
- 세션(session), 프로젝트(project/worktree), 워크스페이스(Desktop `.dat` 단위), 대시보드, 진단(의심 수준), diff(`session_diff` 파일).
- "삭제/정리/복구" 용어는 1단계 UI에 노출 금지. "백업 가이드"만 허용.
