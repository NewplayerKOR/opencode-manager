# Opencode Manager v1.7.0

받는 방법: GitHub Releases 페이지에서 `OpencodeManager.exe` 파일 1개를 내려받아 더블클릭하면 됩니다. 폴더를 뒤질 필요는 없습니다. 서명 없는 파일이라 SmartScreen 안내가 뜨면 "추가 정보"에서 실행을 고르세요. 릴리스마다 SHA-256 해시를 함께 올리니 받으신 파일과 대조해 보세요.

Opencode Desktop에 쌓이는 세션과 프로젝트 현황을 GUI로 확인하는 도구입니다.
Opencode Desktop 사이드바에 보이는 프로젝트(활성)와 DB에만 남은 옛 프로젝트(비활성)를 구분해 보여주고,
프로젝트별 세션명 목록과 메시지 수, 저장소 진단(의심 수준 안내)을 제공합니다.
조회 화면은 읽기전용이며, 정리 기능(V2)은 안전 확인을 전부 통과해야만 동작합니다.

## 실행
- 요구 사항: Python 3.10 이상, Windows.
- 설치: `py -m pip install -r requirements.txt`
- 실행: `py -m src.main`
- 테스트: `pytest tests` (합성 fixture만 사용, 실제 데이터에 손대지 않음)
- 패키지: `py -m PyInstaller --onefile --windowed --name OpencodeManager src/main.py` → `dist/OpencodeManager.exe`
- 배포판: `dist/OpencodeManager.exe` (v1.7.0, 릴리스 에셋으로 배포. 빌드 시점 Python·PySide6 동봉이므로 받는 쪽은 설치 불필요)

## 사용법 (조회)
1. 좌측에서 프로젝트를 고릅니다. 상단 `활성`은 Opencode Desktop에 보이는 것, `비활성`은 DB에만 남은 것입니다.
2. 우측에 해당 세션명 목록이 나옵니다. 행을 고르면 하단에 id, 날짜, 메시지 수, diff 유무가 나옵니다.
3. 하단 진단 영역에 주의 표시(주황)가 있으면 문구를 읽고 직접 확인하세요.
4. 오른쪽 아래 `[새로고침]`으로 수동 갱신, `[복사]`로 선택한 id·경로를 복사합니다.
5. 화면이 작으면 스플리터 위 `[◀ 접기]`·`[접기 ▶]`로 좌·우를 접었다 펼 수 있습니다. 창 크기·테마·글자 크기·글꼴·언어는 `[설정]` 탭에서 바꾸고 기억됩니다. 폰트·언어 변경은 바로 적용됩니다.
6. 상단 `[설정]` 탭에서 언어(한국어·English·日本語·中文), 테마, 글꼴, 글자 크기를 바꿀 수 있습니다. 진단 항목에는 의심 대상이 최대 3건까지 함께 표시됩니다.

## 사용법 (V2 정리)
- 실제 폴더는 지우지 않습니다. 정리 대상은 Opencode가 기억하는 흔적(DB 행·`session_diff`·화면 상태 파일)뿐이며, 소스코드 폴더는 그대로 남습니다.
1. 삭제 전에 Opencode Desktop을 종료하세요. 잠금 표시판이 있으면 정리 버튼이 눌리지 않습니다.
2. 대상을 고릅니다. 세션은 행 선택, 프로젝트 통째 삭제는 좌측 선택.
3. `[세션 보관]`은 목록에서 숨기고 나중에 되돌릴 수 있습니다. `[세션 삭제]`·`[프로젝트 삭제]`는 2번 확인합니다. 활성 프로젝트는 1번 더 묻습니다.
4. 실행 전에 대상 관련분만 자동 백업되고, 제거된 파일은 OS 휴지통으로 이동합니다. 휴지통을 비우면 되돌릴 수 없으니 먼저 확인하세요.
5. `[백업]` 탭에서 백업 목록을 보고 `[복원]`·`[백업 삭제]`를 할 수 있습니다. 백업은 임시 폴더에 평문으로 남으니, 끝나면 `[백업 삭제]`로 휴지통으로 보내세요. 백업 삭제도 2번 확인합니다.
6. 결과가 화면에 나오면 건수를 확인하세요. `[새로고침]`으로 목록을 다시 불러옵니다.

## 주의
- 조회 화면은 읽기전용입니다. 정리 기능은 읽기전용이 아니므로 5번대신 한 번씩 문구를 읽고 진행하세요. 사전 백업이 끝나기 전에는 실행되지 않습니다.
- DB 잠금이나 파일 읽기 실패가 있으면 화면에 안내 문구가 나오고, 강제 해제 같은 조치는 하지 않습니다.
- 이 프로그램은 lockfile 삭제, 프로세스 강제 종료, 자동 정리를 하지 않습니다.
- 자세한 설계와 검증 기록은 `docs/` 폴더에 있습니다.
