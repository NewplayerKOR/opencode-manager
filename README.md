# Opencode Manager v1.7.0

> **실제 소스코드 폴더는 절대 삭제되지 않습니다.** 정리 대상은 Opencode가 기억하는 흔적(DB 행·`session_diff`·화면 상태 파일)뿐이며, 소스코드 폴더는 그대로 남습니다.

Opencode Desktop에 쌓이는 세션과 프로젝트 현황을 보여주는 Windows용 GUI 도구입니다.

## 다운로드 및 빠른 실행
- GitHub Releases 페이지에서 `OpencodeManager.exe` 파일 1개를 내려받아 더블클릭합니다. 별도 설치는 필요 없습니다 (Python·PySide6 동봉 단일 실행 파일).
- 서명 없는 파일이라 SmartScreen 안내가 표시되면 "추가 정보"에서 실행을 선택하세요.
- 릴리스마다 SHA-256 해시를 함께 게시하니 내려받은 파일과 대조해 보세요.

## 주요 기능
- 프로젝트 목록을 활성(Desktop에 표시)과 비활성(DB에만 잔류)으로 구분 표시
- 프로젝트별 세션명 목록과 메시지 수, 세션 상세(id·날짜·diff 유무)
- 저장소 진단: 의심 수준 안내 (R01–R05, 의심 대상 최대 3건 병기)
- 세션 보관·삭제, 프로젝트 삭제 (안전 확인 통과 시에만 동작)
- 백업 보관함: 백업 목록 조회·복원·백업 삭제
- 표시 설정: 언어(한국어·English·日本語·中文), 라이트/다크 테마, 시스템 글꼴, 글자 크기, 창 크기 기억

## 사용 가이드
1. **선택**: 좌측에서 프로젝트를 고릅니다. 상단 `활성`은 Opencode Desktop에 보이는 것, `비활성`은 DB에만 남은 것입니다. 우측 세션 행을 고르면 하단에 상세가 나옵니다.
2. **확인**: 정리 전에 Opencode Desktop을 종료하세요. 잠금 표시판이 있으면 정리 버튼이 눌리지 않습니다. 하단 진단 영역의 주의 표시(주황)는 문구를 읽고 직접 확인하세요.
3. **정리 실행**: `[세션 보관]`은 목록에서 숨기고 나중에 되돌릴 수 있습니다. `[세션 삭제]`·`[프로젝트 삭제]`는 확인 팝업을 2번 거칩니다 (활성 프로젝트는 1번 추가). 실행 전 대상 관련분만 자동 백업됩니다.
4. **사후 확인**: `[새로고침]`으로 목록을 다시 불러와 건수를 확인하세요. `[백업]` 탭에서 `[복원]`·`[백업 삭제]`를 할 수 있습니다.

## 주의
- 조회 화면은 읽기전용입니다. 정리 기능은 다단계 확인 팝업을 거쳐 안전하게 진행되며, 사전 백업이 끝나기 전에는 실행되지 않습니다.
- 제거된 파일은 OS 휴지통으로 이동합니다. 휴지통을 비우면 되돌릴 수 없으니 먼저 확인하세요.
- 백업은 임시 폴더에 평문으로 남으니, 끝나면 `[백업 삭제]`로 휴지통으로 보내세요. 백업 삭제도 2번 확인합니다.
- DB 잠금이나 파일 읽기 실패가 있으면 화면에 안내 문구가 나오고, 강제 해제 같은 조치는 하지 않습니다.
- 이 프로그램은 lockfile 삭제, 프로세스 강제 종료, 자동 정리를 하지 않습니다.
- 자세한 설계와 검증 기록은 `docs/` 폴더에 있습니다.

## 개발 및 빌드 (Developer Guide)
- 요구 사항: Python 3.10 이상, Windows.
- 설치: `py -m pip install -r requirements.txt`
- 실행: `py -m src.main`
- 테스트: `pytest tests` (합성 fixture만 사용, 실제 데이터에 손대지 않음)
- 패키지: `py -m PyInstaller --onefile --windowed --name OpencodeManager src/main.py` → `dist/OpencodeManager.exe` (릴리스 에셋으로 배포, `dist/`는 git 추적 제외)
