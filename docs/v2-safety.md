# v2-safety.md — V2 안전장치 설계 (설계만, 코드 없음)

> 작성일: 2026-10-07 / 상태: v1 초안 / 전제: T12 요구사항(V2-R01–R05) 전제
> 원칙: 안전장치 게이트 전부 통과 전에는 삭제 실행이 불가능한 구조. 본 문서는 설계이며 V1 앱·`src/` 변경 없음.

## 1. 게이트 5종
| ID | 게이트 | 내용 |
|---|---|---|
| S01 | Desktop 종료 확인 | lockfile 존재 또는 Desktop 프로세스 동작 중에는 삭제 경로 차단. 강제 해제·kill 없음, 안내만 |
| S02 | 사전 백업 | 삭제 대상 관련분만 백업 (해당 세션 rows, 해당 `session_diff` 파일, 관련 `.dat` 복사본). 백업본 검증 전 실행 불가 |
| S03 | OS 휴지통 경유 | 제거 대상은 OS 휴지통으로 이동, 영구 삭제 금지. 사용자가 OS 휴지통을 비우면 영구 삭제로 간주하며 사전 고지 |
| S04 | 확정 2단계 | 1차 선택 → 2차 영향범위(건수·용량·연계 파일) 확인 화면 → 확정 클릭. 2차 화면 없이 실행 불가 |
| S05 | 실수 복구 | OS 휴지통 복원 + S02 백업본 복원 절차. 복원 후 건수 대조로 검증 (상세 T16) |

## 2. 실행 흐름 (게이트 순서)
1. 대상 선택 (세션/프로젝트, 보관과 삭제는 별개 선택지)
2. S01 확인 → 미통과 시 중단·안내
3. 영향범위 산정 (읽기전용 조회로 건수·파일 목록 표시)
4. S02 백업 + 검증 → 미통과 시 중단
5. S04 2차 확인 → 확정 클릭 시에만 진행
6. S03 휴지통 이동 → 결과·복원 방법 안내 (S05)

## 3. 게이트 대조 (V2-R01–R04 × S01–S05)
| 요구 | S01 | S02 | S03 | S04 | S05 |
|---|---|---|---|---|---|
| V2-R01 세션 보관 | - (삭제 아님, 종료 무관) | - (원본 유지) | - (숨김 처리) | 2단계 확인 | 복원 제공 |
| V2-R02 세션 삭제 | 필수 | 필수 | 필수 | 필수 | 안내 필수 |
| V2-R03 프로젝트 보관 | - | - | - | 2단계 확인 | 복원 제공 |
| V2-R04 프로젝트 삭제 | 필수 | 필수 | 필수 | 필수 | 안내 필수 |

- 보관(V2-R01·R03)은 숨김+복원이라 S01–S03 면제, S04·S05만 적용.
- 삭제(V2-R02·R04)는 5종 전부 필수. 어느 하나라도 미통과 시 실행 불가.
- T12 제외 3종(lockfile 삭제·프로세스 kill·자동 정리)은 본 설계 어디에도 포함되지 않음.

## 4. T14–T16 인계
- T14·T15는 삭제 흐름 §2를 전제로 연계 범위(cascade·파일 처리)만 확정.
- T16은 S02 포맷·S05 복원 검증을 설계로 확정.
