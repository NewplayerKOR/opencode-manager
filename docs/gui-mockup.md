## 1. 프레임워크 선정: PySide
- 선정: PySide (Qt 모델/뷰).
- 근거: `QTableView`+모델의 정렬/필터가 F01 세션 목록·F03 집계표에 직접 대응. `QSplitter`로 좌측 프로젝트/우측 세션/하단 상세 분할. 고DPI·QSS(파랑/회색 중심) 적용 용이.
- 대가 (명시): 현재 환경에 PySide6/2 미설치 확인 (tkinter 8.6만 내장). 구현 단계에서 `pip install PySide6` 필요, 배포 용량 증가, tkinter 대비 학습비용 있음.
- 1단계 적합성: 읽기전용 뷰어라 Qt 네트워크/쓰기 모듈을 쓰지 않음. 본 목업은 구조 계약까지만, 렌더 검증은 구현 단계 프로토타입으로 이월.

## 2. ASCII 와이어프레임 (구조 계약)
```
+------------------------------------------------------------------+
| 대시보드 바: DB 000.0MB (000,000,000B) | 세션 000건 | 활성 0/비활성 0 |
+--------------------------------+-------------------+-----------------+
| 좌측: 프로젝트         | 우측: 세션 목록      | 하단: 상세      |
| [활성]                 | [ ] title ...      | id: ses_...     |
| [ ] C:\Dev\... (12건)  | [ ] title ...      | 날짜/메시지수   |
| [비활성]               | 빈칸: 조회 결과    | diff 유무       |
| [ ] C:\Old\... (3건)   | 0건 (DB 잠금 확인) | 진단: 주의(주황)|
+--------------------------------+-------------------+-----------------+
| 상태바: 읽기전용 | 마지막 새로고침 0000-00-00 00:00 | [새로고침] [복사] |
+------------------------------------------------------------------+
```
- 좌측 그룹: 활성/비활성 두 그룹 고정, 선택 시 우측 갱신.
- 우측: 세션명(title 우선, fallback은 `(자동 표기)` 꼬리표), 상세는 id/날짜/메시지수/diff 유무.
- 체크박스: 판단 보조 표시용. 실행과 연결 없음.
- 버튼: `[새로고침]` 수동 1개 + `[복사]`만. 자동 폴링 없음.

## 4. `DESIGNS.md` §1–§4 대조
- §1: 2영역 + 상세 패널 + 상태바 구성 준수. 설정 화면 없음.
- §2: 파랑/회색 중심, 주의는 주황까지. 용량 MB 소수 1자리+bytes 병기, 건수 천단위 구분. 빈 상태 원인힌트 포함.
- §3: 화면 경로는 원본 `\`·대소문자 유지, 정규화값은 상세 별도 필드. UNC/`\\wsl$` 별도 배지.
- §4: 쓰기 버튼 없음, 잠금/파싱 실패 크래시 금지(패널 안내), 수동 새로고침만, 경로/ID 복사 제공.

## 5. Non-Goal 검수표 (1단계)
- 실행 버튼류 미포함: 본 문서 ASCII·바인딩표에 실행 동작 없음.
- 체크박스는 판단 보조용으로만 명기, 실행 연결 없음.
- 진단 문구는 "의심" 수준·안내형으로 한정 (확정 판정 없음).
- 검증: 본 파일 내 실행 버튼 문자열 부재를 grep으로 확인 (TASKS 기록 참조).
